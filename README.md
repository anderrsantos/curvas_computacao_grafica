 # Curvas

Projeto de Computação Gráfica com exemplos de curvas implementados em `curvas.py`.

## Sobre o projeto

Este projeto apresenta exemplos de curvas e sua visualização como parte dos estudos de Computação Gráfica.

## Conteúdos abordados

- Representação e visualização de curvas.
- Implementação dos exemplos em Python.
- Execução do programa pelo terminal.

Veja `curvas.py` para conhecer as curvas implementadas e os detalhes de cada exemplo.

## Requisitos

- Python 3 instalado.
- Confira em `curvas.py` se há bibliotecas adicionais necessárias.

## Como executar

No terminal, acesse a pasta do projeto e execute:

```bash
python curvas.py
```

## Arquivos

- `curvas.py`: código-fonte dos exemplos de curvas.
- `README.md`: documentação do projeto.
